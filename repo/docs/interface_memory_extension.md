# Additional annotation-free checks — interface_memory_v1

Specified after inspection of the completed original study, before generating any extension outputs. This is a post-primary robustness extension, not a newly preregistered confirmation and not a replacement for study_v1. User explicitly requested submission preparation without manual annotation.

## Questions
1. Does a variable-named transition schema alter output availability or action-effect fidelity under otherwise identical visible inputs?
2. Can each model retrieve current state, current/past treatment and interval timing from visible histories at two observation times?

## Fixed data and execution
Use all 660 original held-out cases and all four pinned models. No new model fitting, prompt search, clinical annotation or manual output repair. Preserve the original engine, batch size 16, seed, BF16, greedy decoding, 160-token limit and no-retry policy.

Named interface: the exact input object generated by the original state/action prompt is retained. Only the response organization/instructions change: next_state maps variable names to value/lower/upper. Same 95% interval request and numeric units. Run twelve true self-fed steps, stopping each branch on its first invalid point response. No teacher-forced extension; the original feedback experiment remains separate. Parser requires finite values for every variable; intervals are independently valid only if every variable has ordered bounds containing its point. No prefix-content rescue for numerical transitions.

Retrieval: all cases at original anchor and at six observed steps. Construct the latter history by appending exactly the first six reference observations and their already executed actions; no later reference or future action is shown. This is a separate observational-history retrieval task, not feedback into any numerical rollout. Query the fourth-from-last visible row and the preceding interval of the current row. Expected current state, current action, queried past action, and times are copied algorithmically from displayed data. No inferred physiology, estimated real administered dose, clinician judgment or subjective label. This tests explicit-history retrieval and temporal interpretation, not hidden-state identification or persistent conversational memory.

State tolerance 1e-4 native units, actions 1e-6 in displayed rate units, time 1e-8 minutes. Exact shape, finite numeric non-boolean values. Report current-state, current-action, queried-action, temporal and joint accuracy. Both strict single-object and first-object content scores are specified now. The latter ignores trailing prose without repairing values; all tasks remain in the denominator.

## Analysis and denominators
Patient/profile-equal means, 2,000 cluster percentile replicates, seed 20261102. Original and named-schema complete-trajectory MAE, coverage, complete dose/timing-pair effect error and dose-effect sign accuracy (>1 native unit), interval coverage. Named-minus-original errors on exactly matched complete cases/pairs, plus named-minus-zero-effect persistence on named-complete pairs. Report availability differences over every scheduled case. Do not call survivor-only gains overall improvements.

Retrieval results stratified by domain and anchor step; clusters remain original identities/profiles/subjects. Repeated branches and contexts are not independent samples. Retain raw responses and reconstruct every prompt during verification. No pooled world-model score, clinical pass/fail threshold, significance shopping, or assertion of general medical competence.

## Interpretation
This extension evaluates interface sensitivity and fills the prior treatment-history retrieval gap using deterministic labels. It does not provide independent clinical validation, new independent cohorts, more model families, or general treatment safety evidence. All results will be reported regardless of improvement.
