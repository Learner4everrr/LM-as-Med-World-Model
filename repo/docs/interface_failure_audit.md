# Descriptive first-failure audit of the additional interface
Specified after the first named-interface model (Phi) completed and its first failed response in each domain was inspected. Those fixed-order examples used quoted numeric point values. This is a post hoc explanation of interface failures, not a new evaluation condition.

For all four models and domains, classify only each trajectory's first invalid point response. Categories are invalid JSON/non-object, missing schema/variable/value, quoted numeric point values, boolean point values, other nonnumeric/nonfinite values, or other. Numeric-string conversion is used only to identify a category and never to repair a prediction, continue a rollout, change availability, or estimate an unexecuted downstream trajectory. Retain the first example by saved case order; public exports include synthetic examples only. Report every category count, including zeros where applicable. Do not infer a deficit in physiology from serialization failure.
